# M6.19 — User-confirmed FileXio activation

M6.19 exposes the M6.18 FileXio adapter through the System page without activating it during startup.

## Controller flow

From the NEXUS dashboard:

1. Open **System**.
2. Press **Triangle** to open the activation warning.
3. Read the warning: missing IOP modules may be loaded and the required SBV hooks may be applied. No IOP reset, device mount or scan is performed.
4. Press **Cross** to confirm, or **Circle** to cancel. Pressing Start also cancels the prompt and returns Home.

The action handler calls `nexus_filexio_activate()` only after the explicit Cross confirmation while the System page is open. Triangle is inert elsewhere. Once FileXio reports ready, Triangle no longer starts another activation.

## UI states

- **Confirmation required:** IOMANX/FileXio activation prompt with Cross/Circle instructions.
- **Ready:** FileXio RPC is available, but no volume is mounted and no scan has run.
- **Error:** activation failed; the result code is shown and the user may request another confirmed attempt.

The debug-renderer fallback displays the same state and controls if GS initialization fails.

## Safety boundary

This milestone does not add a mount menu or start USB mass/MMCEMAN/APA drivers. It does not launch the scanner after activation. The next milestone will let the user choose among roots that are already registered and accessible, then explicitly request a read-only scan.

No background activation, automatic scan, filesystem write, format, IOP reset or bootloader modification is performed.
