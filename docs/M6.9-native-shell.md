# M6.9 — Native shell bootstrap

**Purpose:** establish a real EE-side executable and DualShock-driven navigation base without pretending to recover the missing historical M1–M5 source.

## New source layout

- src/nexus_main.c — native entry point, SIF RPC startup, debug renderer startup and input loop.
- src/nexus_input.c — PS2SDK libpad backend for controller port 0 / slot 0.
- src/nexus_navigation.c — platform-independent page/navigation state machine.
- src/nexus_ui.c — first dashboard plus separate Games, PS1, Homebrew, Store, Files and System screens.
- src/nexus_devices.c — conservative device snapshot contract.
- src/include/ — native interfaces and portable navigation model.
- src/Makefile — PS2SDK EE executable target producing NEXUS.ELF.

## Controller input

The backend loads ROM0 SIO2MAN and PADMAN through SifLoadModule, initializes libpad, and opens pad port 0 / slot 0. Its DMA work area is 256 bytes and 64-byte aligned, as required by the current PS2SDK libpad header. It reads the controller only when padGetState() reports PAD_STATE_STABLE and converts the active-low button bitmask into edge-triggered navigation events.

Bootstrap controls:

| Controller | Action |
|---|---|
| D-pad up/down | Select a home section |
| Cross | Open selected section |
| L1/R1 | Previous/next section |
| Circle | Back to dashboard |
| Start | Return home |

## Dashboard behavior

The initial text dashboard shows Disc, MC0, MC1, HDD, MMCE and USB status slots. Every slot remains NOT PROBED until a real detection provider is implemented. Hardware observations in project documentation are not presented as a live device scan.

Each section has its own screen. The Games page documents intended storage sources and OPL/Neutrino adapters but does not scan or launch games yet. The Store page explicitly reports that the host-side signed catalog pipeline exists while the native PS2 network transport and installer do not.

## Build

With the official PS2DEV toolchain and PS2SDK installed and configured:

~~~sh
make -C src
~~~

This follows the upstream PS2SDK sample pattern using Makefile.pref and Makefile.eeglobal, linking libpad and libdebug. The output is src/NEXUS.ELF.

## Validation

GitHub Actions now compiles the platform-independent navigation module with the host C compiler and runs its navigation tests. This does not compile the PS2-specific files and does not substitute for the PS2SDK cross-build or a console test.

## Known boundary

- The renderer is PS2SDK debug text, not the final GS graphics UI.
- No GS primitive/texture/font/artwork pipeline is included yet.
- No live device probing, mount handling or filesystem modification.
- No OPL/Neutrino launch handoff.
- No PS2-side Store Bridge, TLS, Ed25519 or package installation.
- No changes to OSDSYS, FMCB, FHDB, PSBBN or other boot paths.
