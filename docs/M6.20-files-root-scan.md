# M6.20 — Files root selection and confirmed read-only scan

M6.20 connects the user-confirmed FileXio service to the existing M6.17 scanner core. It does not initialize block drivers or mount devices.

## Root allowlist

The Files page exposes three fixed roots:

| Display label | Root | Catalog source |
|---|---|---|
| USB MASS STORAGE | `mass:/` | USB |
| MMCE SLOT 0 | `mmce0:/` | MMCE |
| MMCE SLOT 1 | `mmce1:/` | MMCE |

Use Up/Down to select a root. These paths are hard-coded; there is no arbitrary path input and no path is assembled from user-controlled text.

## Controller flow

1. In **System**, activate FileXio explicitly using Triangle → warning → Cross. Circle cancels. This loads missing IOMANX/FileXio RPC modules and initializes FileXio; it does not start USB/MMCE drivers, mount anything or scan.
2. Open **Files**. If FileXio is not ready, the screen tells the user to activate it in System first.
3. With FileXio ready, use Up/Down to select `mass:/`, `mmce0:/` or `mmce1:/`.
4. Press Triangle to open the scan confirmation.
5. Press Cross to scan, Circle to cancel, or Start to cancel and return Home.

The scan runs only after the second confirmation. The action handler passes the selected root and source to `nexus_filexio_scan_root()`.

## What gets scanned

The M6.17 scanner confirms that the selected root is already accessible, then opens only its direct:

- `CD/` and `DVD/` directories for PS2 `.iso` / `.zso`.
- `POPS/` directory for PS1 `.vcd`.

It does not recurse, follow links, enumerate APA/PFS partitions, or launch titles. The Files panel reports the scan return code and counts for indexed, seen and rejected entries. Results enter the in-memory catalog; persistent metadata/favorites and cover-art population are separate work.

## Safety / availability

- The root list is an allowlist and selection itself performs no I/O.
- The scanner calls only FileXio Dopen/Dread/Dclose through the read-only adapter.
- There are no mount, unmount, write, delete, rename, format or driver-start calls in this action.
- FileXio readiness does not imply a root is available. A selected root returns an error if the underlying device driver/filesystem is not already registered and accessible.
- In particular, this milestone does not start `mass` or MMCEMAN. It will not make unavailable hardware appear.
- Traditional internal HDD APA/PFS games are not file-based CD/DVD folders and need a separate read-only partition provider.

## Next step

M6.21 should add a real read-only USB mass driver/provider lifecycle only behind explicit user intent, plus availability probes for `mass:/` and the MMCE roots. The traditional internal HDD needs its own APA/PFS reader and must not be misrepresented by this folder scanner.
