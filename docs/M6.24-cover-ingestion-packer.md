# M6.24 — Deterministic cover-art ingestion packer

M6.24 adds the first complete, host-side artwork ingestion stage for the existing four-slot native GS cover cache.

## Implemented

- Reads user-supplied PNG covers from a selected directory; it does not download copyrighted artwork.
- Uses the repository's bounded PNG decoder (8-bit RGB/RGBA, non-interlaced, CRC checked).
- Fits each cover into a 128×128 texture without stretching: aspect ratio is preserved and unused space is letterboxed.
- Emits row-major PSMCT32-compatible RGBA32 payloads and a `covers.json` manifest.
- Records source and output SHA-256 values, source dimensions, stable IDs and exact texture format.
- Caps the input set at 96 images and each source at 4 MiB.
- Includes a verifier that checks manifest structure, safe output names, payload size and hashes. Symlinked output directories, manifests and payloads are rejected.
- Decodes the complete source set before publishing any payload, so a malformed later image does not leave a partial pack.

## Build and verify

```sh
python3 tools/nexus_cover_pack.py ./my-cover-pngs ./build/covers
python3 tools/nexus_cover_pack.py --verify ./my-cover-pngs ./build/covers
```

## Boundary

This milestone prepares data for the native cache; it does not yet resolve game IDs to cover filenames, read the pack from a PS2 device, or schedule DMA uploads. Native integration and PCSX2/physical-PS2 visual checks remain separate gates. The packer is deterministic for the same source PNG bytes and filenames.


## Transactional publication

Cover pack generation stages every converted RGBA payload and the manifest in a private temporary directory, flushes staged files, backs up existing outputs, and publishes the manifest last. If any rename fails, newly published files are removed and the previous payloads and manifest are restored. If rollback itself fails, the staging directory and recovery copies are retained and the error reports their location. Host tests inject a mid-commit failure and verify the old pack remains verifiable.
