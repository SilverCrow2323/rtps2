# M6.22 — Visual redesign of the native GS interface

M6.22 replaces the first debug-like 3×2 card dashboard with a more deliberate console UI. It is a substantial visual foundation pass, not the final animated skin.

## Visual language

- Deep navy background, layered blue panels and restrained cyan accents.
- Muted blue-grey secondary text; amber is reserved for waiting, error and confirmation states.
- Thin divider lines and small accent edges establish hierarchy instead of outlining every object.
- FontX/KROM remains the native PS2 font. The renderer enables the bold option and uses bounded text fitting and truncation for the 640-pixel output width.
- The same top bar, accent line and command footer are reused across Home and module pages.

## Home dashboard

The Home layout now has three distinct regions:

1. **Navigation rail** on the left: six fixed modules (Games, PS1 Library, Homebrew, NEXUS Store, Files and System), each with a compact icon, title and subtitle. The active module receives a filled selection surface and cyan marker.
2. **Contextual hero** on the right: the highlighted module gets its title, short explanation, capability line, live catalog or FileXio state where available, a large section icon and position indicator.
3. **Status metrics** below the hero: game catalog count, GS atlas state and controller state.

PAL and NTSC use the same 640-pixel width but different vertical budgets (512 and 448 lines). The hero height, navigation row height, metrics and footer are derived from the active region.

## Module pages

Generic modules use a consistent two-column composition:

- Main overview panel with section icon, concise description and next action.
- Three compact status panels for module state, controller/input and video/graphics.
- One command footer with the controls relevant to the current state.

Files keeps the confirmation and scan-result messages. System keeps the explicit FileXio activation warning and ready/error states. The visual layer does not add an implicit mount, device start or filesystem write.

## Games presentation

Games uses the M6.16 catalog and M6.21 view state. The four modes remain Grid, Carousel, Coverflow and List.

Cards now have a deliberate cover-art region, metadata strip, PS1/PS2 badge, favorite mark and selection frame. Width-aware labels prevent side cards in Coverflow from receiving full-width text.

**Artwork status:** the cards currently show section icons and an explicit ARTWORK NOT CACHED placeholder. They are not real game covers. The M6.15 four-slot GS cache exists, but a bounded image decoder, format validation, source-to-artwork mapping and cache population still need to be connected.

Cross opens metadata only. The UI does not start OPL, Neutrino or POPS until a version-aware launch handoff has been proven.

## Controls represented in Games

| Control | Action |
|---|---|
| Up / Down | Move the selected title |
| Cross | Open title details |
| Circle | Close title details / go back |
| Triangle | Cycle Grid → Carousel → Coverflow → List |
| Square | Toggle favorite |
| L2 | Cycle source filter |
| R2 | Cycle platform filter |
| L1 / R1 | Switch modules |
